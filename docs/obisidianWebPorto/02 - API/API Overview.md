# API Overview

All Next.js App Router API endpoints exist inside `app/api/`.

## Endpoints

- [[auth API]]: Authentication (NextAuth).
- [[skills API]]: CRUD for `skills` table.
- [[projects API]]: CRUD for `projects` table.
- [[certifications API]]: CRUD for `certifications` table.
- [[resume API]]: Singleton document management.
- [[portfolio API]]: Singleton document management.
- [[upload API]]: File upload handler to S3/MinIO.
- [[chat API]]: AI chatbot interface using Hermes API and Upstash Redis rate limiting.
